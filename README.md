
# Customer Churn Prediction using XGBoost

## Project Overview

This project predicts whether a bank customer
will leave the bank using Machine Learning.

An XGBoost Classifier is used to train the
model and predict customer churn.

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- XGBoost
- Matplotlib

## Machine Learning Workflow

1. Data Loading
2. Data Preprocessing
3. One-Hot Encoding
4. Train-Test Split
5. XGBoost Model Training
6. Model Prediction
7. Model Evaluation
8. Cross Validation

## Algorithm

XGBoost Classifier

## Evaluation Metrics

- Confusion Matrix
- Accuracy
- Precision
- Recall
- F1 Score
- Cross Validation

## Installation

Clone the repository:

git clone YOUR_GITHUB_REPOSITORY_URL

Install dependencies:

pip install -r requirements.txt

Run the project:

python churn_prediction.py

## Dataset

Churn Modelling dataset.

Place the downloaded CSV file inside the
dataset folder as Churn_Modelling.csv.
